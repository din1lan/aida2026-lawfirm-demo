# 客戶進度回報草稿：做了什麼

> 2026-11-04｜分支 `feature/progress-report`（**沒有動 main**，沒有開 PR）｜規格見 [進度回報-規格.md](進度回報-規格.md)

## 一句話

案件詳情多了一顆「📨 產生進度回報」按鈕。按下去，系統用固定句型把這件案件的進度寫成一則給當事人的訊息，律師可以改字，再按「複製」貼到 LINE 或 Email。**系統不會自動寄出，也不會把資料送到任何地方**（不用 AI、不用金鑰、不連網）。

## 怎麼用

1. 「案件管理」→ 點案號或「🔎 詳情」打開案件詳情
2. 按右上方「📨 產生進度回報」
3. （選填）補「最近一次開庭結果」「需要當事人準備的事」兩格，草稿會自動更新；這兩格會記在該案件上，下次打開還在
4. 直接在草稿框改字 → 按「📋 複製」→ 自己貼到 LINE / Email

草稿內容（資料缺的段落自動不寫）：稱呼 → 案件與案號 → 目前進度（白話）→ 上次開庭 → 下次開庭（日期、時間、地點）→ 30 天內的重要日期 → 需要您協助準備 → **「如有疑問，歡迎與我們聯絡。」** → 律師署名。

**不會出現**：身分證、電話、收費／代墊款、對造資料、事務所內部任務與提醒、對結果的預測或保證。律師自己打的字若有「保證」「勝訴」或疑似身分證／手機號碼，畫面會出黃色提醒（不自動刪）。

## 證據

**1. Node 測試：16 通過、0 失敗**（`node tests/progress-report.test.js`）
涵蓋：資料齊全、沒有下次開庭、沒有期限、什麼都沒有、欄位只填「—／無／未填」、欄位很長、整日開庭、多場開庭只列最近一場、當天開庭、調解中／執行／已結案、壞資料（格式錯、null）、跨年日期、條列符號清理、內部提醒與筆錄調閱不外流、一般法定期限的說法、警示字眼偵測。每個案例都檢查不出現「未填／undefined／保證／勝訴」、不洩漏身分證與金額、一定有結尾句。

**2. 瀏覽器實測（Playwright）**（`node tests/progress-report.e2e.js`）
- 3 件示範案件都產生草稿並截圖：

  - `docs/screenshots/progress-report-c2.png` 陳美惠（調解中、只有法定期限、沒有開庭）
  - `docs/screenshots/progress-report-c3.png` 黃志豪（只有下次開庭）
  - `docs/screenshots/progress-report-warning.png` 律師手動加「保證勝訴」→ 出現黃色提醒；按「複製」成功

- 沒有設定 AI 時，看不到「AI 潤稿」按鈕

- 註：示範資料的開庭／期限落在 2026 年 7–8 月，所以測試時把瀏覽器日期固定在 2026-07-20，才看得到「下次開庭」「近期期限」。用今天（11/4）開，這 3 件只會顯示「目前進度」，這是資料本身已過期，不是壞掉

## 之後要接 AI 潤稿

已預留接點，這次沒做：

```js
ProgressReport.setPolisher(async (text) => { /* 回傳潤稿後文字 */ });
```

設定後草稿視窗才會出現「✨ AI 潤稿」按鈕。接的時候要注意：草稿會送到外部 AI，需另外取得同意、處理金鑰與個資。
