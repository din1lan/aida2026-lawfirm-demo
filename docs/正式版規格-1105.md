### 1. 期限規則改成法律規定（末日遇非工作日順延到次一工作日）

| | 改前 | 改後 |
|---|---|---|
| 規則 | 末日遇週末、國定假日 → **往前**調到前一個工作日 | 末日遇週末、國定假日 → **順延到次一工作日**（民法第 122 條；民事訴訟法第 161 條準用） |
| 例：收文 10/19、民事判決上訴 20 日 | 第 20 日 11/8（週日）→ 11/6（週五） | → **11/9（週一）**；提前提醒（14～20 日提前 5 日）→ **11/4** |
| 例：民事裁定 10 日，收文 10/14 | 10/24 → 10/23 | 10/24～10/26 連假 → **10/27** |
| 例：刑事判決 20 日，收文 9/5 | 9/25 → 9/24 | 9/25～9/28 中秋連假 → **9/29** |
| 一般期限（`computeDeadlineDate`） | 不看假日 | 同樣順延到次一工作日 |
| 示範資料日期平移 | 平移任意天數，期限可能落在週六（例：補繳裁判費 7/25 週六）、開庭落在週日 | 平移整週（星期幾不變），平移後期限用同一套規則重算，提前提醒跟著重算 |
| 提前 N 天提醒 | 有 | **保留**，分級表不變（從順延後的末日往前推） |

改到的地方：`index.html`（`nextBusinessDay`、`computeActionDeadline`、`computeDeadlineDate`、表單說明、試算畫面「已順延到次一工作日」、示範資料平移）、`modules/autofill.js`（畫面文字）、`tests/autofill.test.js`（預期值＋新測試 4b：2026～2027 每一天 × 5／10／20 日，末日不會早於第 N 日、中間跳過的都不是工作日）、`tests/demo-dates.e2e.js`（新）、`docs/AI自動填-*.md`。
