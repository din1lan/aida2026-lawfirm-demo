# 法律事務所 AI 案件管理系統（AIDA 2026 比賽示範版）

- **所有資料皆為虛構**：律師、當事人、案件、利益衝突名單都是示範用的假資料，不含任何真實個資
- **沒有任何雲端連線**：不連資料庫、不需登入帳號；資料只存在使用者自己的瀏覽器
- 登入：選一個身分直接進入，不需密碼
- AI 智慧閱卷：自備 Google Gemini API 金鑰即可上傳全案文件、整理爭點；沒有金鑰時可切換「示意版」體驗流程（正式使用為 Gemini）。金鑰只存在瀏覽器分頁，不會寫進檔案
- `01_民事起訴狀.pdf`～`04_原告民事準備書狀.pdf`：同一件虛構案件的 4 份文件，在「AI 智慧閱卷」按「載入示範案件」即可一次讀入，示範全案整理與點「原文」跳到該份文件原句
- 全案整理結果可匯出 HTML 或 PDF（列印）存到事務所資料夾；之後把報告連同新文件一起上傳，AI 會把它當作前次整理的背景，接著更新進度（報告內容不會被當成「原文」出處）
- 案件類型（民事／刑事／行政）由 AI 依文件內容自行判斷
- `示範卷宗.pdf`：舊版單份示範文件
