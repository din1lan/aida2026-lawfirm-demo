**實際看到的（有截圖或測試紀錄）**
- 一鍵示範的步驟和時間、每頁每顆按鈕的點擊結果、console／資源錯誤數（`qa/data/*.json`）

- Git 歷史掃描結果、PDF 內文與屬性

**推論（沒辦法直接驗證）**
- GitHub Pages 從 `main` 發布：看不到 repo 設定，只能從「只有 main 一個分支」推定
- 線上版和本機版行為一樣：線上網址在這台機器打不開；外部套件是用同版本頂替的，Tailwind 是預先編好的 3.4.17，不是 CDN 現場產生
- Slow 3G 的秒數：外部套件的下載時間是用檔案大小估算的延遲，實際現場會受網路、快取影響。結論（PDF 15 秒內載不完就會失敗）不受影響
- 密碼有沒有在別處用過：只有你們知道（M6）
- 站外連結（勞保局、Google 日曆）能不能開：這台機器連不出去，只檢查了網址格式
